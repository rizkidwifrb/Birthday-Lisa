# Lisa Day
Website ulang tahun untuk Lisa Fadhillah Putri, dari Rizki Dwi Febriansyah.

## Jalankan
Buka dist/index.html di browser. Tidak perlu instalasi atau build.
Alternatif: jalankan `python3 -m http.server 8000 --directory dist` lalu buka http://localhost:8000.

## Isi
- Scrapbook responsif dan 5 aset foto dari pengguna.
- Surat ucapan ulang tahun, galeri foto, 8 doa bergantian.
- Konfeti dan lilin interaktif. Tanpa pengakuan romantis atau easter egg romantis.
- Dialog foto mendukung Escape, navigasi keyboard, dan preferensi reduced motion.

## Edit
Teks utama: dist/index.html. Warna/layout: dist/style.css. Interaksi dan doa: dist/script.js.
Font Google dimuat jika online; tersedia font pengganti saat offline. Foto tersimpan lokal.

## Hosting
Upload seluruh isi folder dist ke hosting statis pilihan. Jangan unggah foto secara publik jika tidak diinginkan.
